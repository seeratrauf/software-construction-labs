- `pytest` (used in Lab 2 and Lab 4 for unit tests)

Install pytest with:

```bash

```

Each file can be run directly:

```bash

```

Labs 2 and 4 contain pytest-based tests. Run them with:

```bash

pytest -q "Lab 4 Seerat Rauf (SP24-BSE-27).py"
```
